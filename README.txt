Put your pictures in this folder using these exact file names:

  profile.jpg        Your portrait (portrait orientation, about 800 x 1000 px)
  anidaso-green.png  Screenshot of the Anidaso Green Initiative site (about 1200 x 750 px)
  portfolio.png      Screenshot of this portfolio (about 1200 x 750 px)

Until a file exists, the site shows a lettered block instead, so nothing looks broken.
To use different file names, change the paths in src/profile.ts and src/projects.ts,
then run: npm run build
